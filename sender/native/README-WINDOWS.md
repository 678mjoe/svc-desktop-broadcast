# P4C Windows 11 x64 原生音源测试

解压后，以普通用户在此目录打开 PowerShell。程序使用 Windows 自带的 WASAPI，可同时检查 1–4 个明确指定的应用进程树。整个测试只显示本机电平，无需安装 OBS、虚拟声卡或 Python，无需 Minecraft、配对或连接服务器。

## 1. 核对音源

1. 打开网易云音乐和另一款播放器，两款都选一首能正常播放的曲目。再准备一个第三音源，例如浏览器里的视频，用于验证排除。
2. 在任务管理器的「进程」里找到播放器，右键该应用的主进程，选择「转到详细信息」，记下 PID。只选每款播放器的根进程，因为其子进程已包含在同一条采集里。
3. 在 PowerShell 运行以下命令，核对工具能启动。下文的 12345 和 23456 分别替换为两款播放器的实际 PID。程序启动检查时会显示所选 PID 和文件名。

   .\svc-wasapi-check.exe --help

## 2. 单应用与隔离

   .\svc-wasapi-check.exe check 12345 45

播放网易云，确认出现 SIGNAL。暂停网易云，再让未选中的浏览器播放。浏览器在播时，网易云的电平应仍为 SILENT 或 NO_SAMPLES。恢复网易云后，同一次检查应再次出现 SIGNAL。按 Ctrl+C 提前停止并返回 PowerShell。

## 3. 两个应用同时采集

   .\svc-wasapi-check.exe check "12345,23456" 60

先同时播放两款应用，确认两个 PID 都出现 SIGNAL。然后分别暂停、恢复一款，确认另一款仍有信号。最后暂停两款，让未选中的浏览器继续播放，确认两条电平都为零。只要某路恢复播放，该路就应在同一次检查里重新出现 SIGNAL。

此包分别显示两路电平。两路混音并广播需要后续的发送器接入测试。

## 4. 退出和结果

再开一次双应用检查，并从播放器菜单退出其中一款。工具应报告对应 PID 退出，随后结束本次检查。测试完把结果填入 TEST-RESULTS.txt。

SIGNAL 表示该秒收到非零样本，SILENT 表示收到的样本为零，NO_SAMPLES 表示该秒没有样本。若播放中的应用一直没有信号，请记录播放器和目标进程名、PID、Windows 版本及具体报错（例如 HRESULT）。
